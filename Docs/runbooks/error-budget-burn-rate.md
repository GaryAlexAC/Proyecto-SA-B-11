# Runbook: burn rate del error budget

1. Identificar el SLO afectado y la ventana de la alerta.
2. Comparar error rate, latencia y disponibilidad en Grafana.
3. Revisar los postmortems o despliegues recientes.
4. Mitigar el incidente antes de continuar con cambios no urgentes.
5. Registrar la evidencia y actualizar el postmortem blameless.
